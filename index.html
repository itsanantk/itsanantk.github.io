03 / Projects

Things I've built

FIG. H

FPGA Neural-Net Inference Accelerator

A single-layer neural network (MAC unit) on a DE1-SoC in SystemVerilog, pipelined into load / multiply / accumulate stages to shorten the critical path, with a 24-bit accumulator sized from bit-growth analysis. Verified against a reference model with a self-checking testbench covering the corner cases; a pipeline-drain bug (the final result never flushing through) was found by waveform analysis of valid-in/valid-out timing and fixed with a drain state. A memory-mapped C++ driver on the ARM HPS under embedded Linux reaches 3,000 inferences/sec — a 300% speedup over ARM-only execution.

SystemVerilog · FPGA · Self-checking testbench · C++ · ARM · Embedded Linux

FIG. I

Digital Systems Design

A CPU datapath and control (ALU, register file, control FSM) and a debounced keyboard interface with a two-flop synchronizer, in SystemVerilog on a DE10-Lite. Self-checking, vector-driven testbenches in QuestaSim: golden vectors loaded from file, stimulus driven and checked on opposite clock edges, four-state comparison, pass/fail reporting.

SystemVerilog · QuestaSim · Intel Quartus · DE10-Lite

FIG. J GitHub ↗

GPU Inference Benchmark

Cross-stack inference benchmark isolating compilation gains from precision gains with a three-rung ladder (PyTorch to TensorRT FP32 to TensorRT FP16) on an RTX 3080 — 50 warmup runs discarded, torch.cuda.synchronize() around every timing, median/p95 against a measured ±0.5 ms noise floor. Then ported to AMD's MI300X via ROCm/MIGraphX, where unoptimized PyTorch FP32 (1,143 fps) already beats the fully-optimized TensorRT FP16 engine on the 3080 (1,008 fps) on raw hardware scale, and MIGraphX FP16 scales from batch 1 to 8 to 7,277 fps with near-zero added latency.

Python · PyTorch · CUDA/TensorRT · ROCm/MIGraphX
